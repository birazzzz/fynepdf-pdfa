## The fonts (`fonts/`)

Free fonts embedded in place of fonts a PDF names without embedding. Each keeps its licence,
in `fonts/licenses/`; `fonts/SOURCES.md` says where each came from and `fonts/SHA256SUMS`
checks them.

| Files | Licence |
| --- | --- |
| Arimo, Tinos, Cousine, Carlito, Caladea, Noto Sans, Noto Serif | SIL Open Font License 1.1 |
| DejaVu Sans | Bitstream Vera licence (DejaVu changes in the public domain) |
| Droid Sans Fallback | Apache-2.0 |
| Adobe CMaps (`fonts/cmaps/Uni*-UCS2-[HV]`) | BSD-3-Clause, © Adobe |

A PDF made PDF/A carries subsets of these fonts; their licences allow that.
