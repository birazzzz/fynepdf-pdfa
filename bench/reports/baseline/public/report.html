PDF/A Converter Bench

Run baseline, 2026-10-24. Every tool converts the same files; veraPDF checks the results; pdf.js and Poppler check what each conversion kept and how the pages look.

Files

  • A. Feature set: 56 files
  • E. Office and print: 11 files
  • B. Rule set (veraPDF corpus): 1771 files
  • C. Real world (1,000 web PDFs): 1000 files (results and file numbers only; the files aren't redistributed)
